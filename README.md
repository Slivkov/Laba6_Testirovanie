# Крестики-нолики

Лабораторная работа по предмету "Методы отладки и тестирования программных продуктов".

## Описание проекта
Это простые крестики-нолики на Python. Сделано с Tkinter.

## Текущий функционал
- Игровое поле 3х3
- Поочередный ход игрока и алгоритма
- Проверка победных комбинаций

## Запуск игры
Запустите файл `KRESTIKI-NOLIKI.py`

## Процесс разработки
Используется Git:
- `main` - стабильные версии
- `dev` - ветка разработки
- `feature/*` - ветки для новой функциональности
